# Minecraft Server Butler

Minecraft Server Butler is a lightweight tool that automates the routine administration of a self-hosted Minecraft: Java Edition server on Linux using standard system components. It aims to make self-hosting reliable, transparent, and approachable while remaining faithful to standard Linux administration practices.

Project philosophy: **Make the right way the easy way.**

### Project Status

This project is under active development. It is currently used to manage the author's own production server but is not yet ready for general use.

### Features

- Systemd integration
- Configurable settings
- Operational logging
- Automated `server.jar` updates
- Automated backups
- Automated corruption detection and remediation
- Automated maintenance breaks
